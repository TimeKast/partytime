# User stories — guest management upgrades

- **US-001:** Como administrador, quiero ordenar y paginar invitados para revisar listas grandes sin perder contexto.
- **US-002:** Como administrador, quiero que PDF/Excel respeten búsqueda, filtros y orden para compartir la lista preparada.
- **US-003:** Como manager, quiero generar un link de un uso con vigencia para admitir una excepción privada.
- **US-004:** Como manager, quiero ver estado y revocar links pendientes para controlar accesos emitidos.
- **US-005:** Como invitado, quiero registrarme mediante mi link aunque el RSVP público esté cerrado.
