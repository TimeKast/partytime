# User personas — guest management upgrades

## Event manager

Opera un evento concreto, prepara listas y necesita conceder excepciones sin reabrir el RSVP para todos. Requiere controles claros, confirmaciones y estados de vigencia/uso.

## Event viewer

Necesita leer y exportar listas, pero no debe generar, revocar ni consumir capacidades administrativas.

## Invited guest

Recibe un URL privado, normalmente desde móvil. Necesita entender evento, expiración/error y completar el mismo formulario RSVP accesible.
